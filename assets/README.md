# Assets

## ghibli-grain.jpg

Place a seamless 4K (or at least 1024×1024) hand-painted / paper grain texture here named `ghibli-grain.jpg`.

Recommended characteristics:
- Subtle beige / warm paper tone
- Seamless tileable
- Low contrast noise (not too strong)
- JPEG quality 85+

If the file is missing the engine falls back to a procedural 2×2 paper texture so the demo still works.
